# S19 OPN F2: 幅 2048 の副 net の推論 6 項目

- 状態: 採用 / bit 一致: 一致 (非 PGO で評価値・探索とも旧 exe と完全一致) / requires: M00
- 人間向け: `../SPEEDUPS_STORY.md` 8.2 節

## 1. 要約

序盤専用の幅 2048 の NNUE (FT 2048 x 2 視点、 fc0 2048 → 16) を、 素直な実装 (本体だけの版の約 80% の NPS) から速くした 6 項目。 置き換えで x1 → f5 が +17%、 x2 → f5 が +9%。 幅 1024 の NNUE にも使える項目がある (★)。

## 2. 前提と項目

前提: FT の差分更新 (多段の追いつきを含む)、 Finny 表、 transform、 疎でない (密な) fc0 を AVX2 で持つ NNUE。 幅が大きく、 FT の 1 行 (i16 x 2048 = 4 KB) が 1 ページになる。

| 項目 | 中身 | 効いた量 (rdtsc、 OPN の費用) |
|---|---|---|
| ★F2-1 fc0 の重みの先読み | fc0 の積和のループで、 重みを 2 KB 先まで `_mm_prefetch` | fc0 + 後段 −16% (幅 2048) / −15〜17% (幅 1024) |
| F2-2 差分行の先読み | 差分更新で足す行を 4 line 先まで先読み | 3〜5 line が最良、 0 / 8 / 16 は悪化 |
| F2-3 FT を 4096 B 整列 | 幅 2048 の i16 = 1 行 4 KB を 1 ページに合わせる | −1.1〜−3.6% |
| F2-4 区分が同じなら差分 | 玉が動いても、 玉の区分 (K16) と鏡像が同じなら refresh でなく差分 | — |
| ★F2-5 priming で作らない | 探索の priming で acc を作らず、 子が 2 手以上を跨いで追いつくときに親の acc を作って残す | −2.3〜−4.7%。 priming を単にやめると +14.9% の悪化 |
| ★F2-6 差分と transform の融合 | 差分更新の最後の列ループで transform まで書く (acc を書いた直後のレジスタから) | −430 cycle/評価 (acc +269 / transform −733) |

| 本実装 | 場所 |
|---|---|
| 推論 | `<engine>/source/eval/p2nnue/p2nnue_opn.h` (`affine_fc0_pf`、 `apply_rows_tr2_t` ほか) |
| define | `-DP2_OPN -DP2_OPN_F2` (個別: `P2_OPN_FC0_PF_BYTES`、 `P2_OPN_ROW_PF_LINES`、 `P2_OPN_F2_NOPAGE`、 `P2_OPN_F2_EAGER_PRIME`) |

## 3. 不変条件

- どの項目も値を変えない。 F2-5 は「親の acc を作るときの値」が全計算と同じ (差分の可換性)。 F2-6 は transform の式が同じ。

## 4. 変更の最小単位

項目ごとに独立 (F2-6 は F2-2 の後)。 1 項目ずつ:
1. 計測ビルドで、 評価の各部分 (acc / transform / fc0 / 後段) を rdtsc で測る器を先に作る (同じプロセスの中で 4,096 評価ごとに方式を切り替えると、 同じ局面列で比べられる)。
2. 項目を入れ、 静的評価の一致 (全局面) と探索の一致 (32 局面 depth 18 程度) を確かめる。
3. rdtsc で費用の変化を見る。 悪化したら外す。
4. 全部入れたら M00 の NPS (置き換え = 同じ探索木で比べる)。

## 5. bit 一致の検証

非 PGO は評価値・探索とも旧 exe と完全一致。 🚨PGO 版は 9 設定中 1 設定で 32 局面中 1 局面が違ったが、 F2 を入れない PGO でも同じ値だった (PGO の側の非決定性。 F2 の誤りではない)。

## 6. NPS の測り方と期待値

我々: 置き換え・同じ探索木で x1 → f5 +17%、 x2 → f5 +9% (8 局面、 50 万ノード x 3 周、 非 PGO)。 OPN なしの base に対して 91.2% / 95.4% まで戻った。

## 7. はまりどころ

- 先読みの距離は振って決める (近すぎても遠すぎても悪化)。
- priming をやめるだけでは悪化する。 「子が追いつくときに親を作って残す」までやる。
- HT の相方が埋まると核の cycle が 1.5 倍になる。 rdtsc の比較は同じ条件で。
